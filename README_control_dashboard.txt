PawCare 배송 관제 · RoboDog 배송과 관측소 신호 통합

실행 파일
- robodog_abc_delivery.py : PC Thonny용 Python. RoboDog 배송 제어, 관측소 시리얼 수신, 관제 웹 서버를 함께 실행합니다.
- pawcare_control.html : 배송 지도, 로봇 위치, 재난 신호와 관측소 센서 상태를 보여줍니다.
- 눈 LED 버튼으로 로보독 눈을 켜고 끌 수 있으며 운행 중에도 조작할 수 있습니다.
- 운행 중 `출발점으로 귀환`을 누르면 현재 위치에서 귀환 경로로 바꿉니다.
- `운행 기록`에 여러 운행의 결과와 이벤트가 저장됩니다. 최근 운행은 화면에서 보고 전체 기록은 CSV로 받을 수 있습니다.

첨부된 상대 Python 코드와의 관계
- 첨부된 Python 코드는 송신기가 아니라 수신·주행 프로그램입니다. `serial.Serial(COM6, 115200)`으로 micro:bit USB 시리얼을 열고 `read()`로 들어오는 내용을 읽습니다.
- 이 코드는 다음처럼 쉼표로 나눈 한 줄을 받도록 작성되어 있습니다: `OBS,관측소번호,불꽃값,가스AO값,가스DO값` (줄 끝은 개행).
- 예: `OBS,1,1,500,0`은 1번 관측소, 불꽃값 1, 가스 AO 원시값 500, 가스 DO 원시값 0을 뜻합니다.
- 받은 값으로 관측소 1을 A·B 구역, 관측소 2를 B·C 구역에 연결하고, 별도 순찰 동작으로 RoboDog를 움직입니다. HTML 서버 기능은 첨부 코드에 없습니다.
- 첨부 코드의 RoboDog 포트는 COM5지만 이는 그 코드가 사용하던 PC의 설정입니다. 이 프로젝트에서 확인한 RoboDog 포트는 COM8이므로 기본값 COM8을 유지합니다.

통합 프로그램의 연결 방식
- 이 프로젝트의 Python은 기본 COM6, 115200 baud에서 위 `OBS,...` 줄을 읽고 같은 형식의 패킷을 처리합니다. 따라서 첨부 코드의 데이터 형식에 맞춰져 있습니다.
- RoboDog는 기본 COM8을 사용합니다. 포트가 다르면 `MICROBIT_PORT` 또는 `ROBODOG_PORT` 환경 변수를 설정하세요.
- Python이 받은 센서 상태를 HTML 관제 화면에 제공하고, 배송 동작과 위험 알림을 함께 처리합니다. HTML 페이지가 micro:bit 시리얼을 직접 읽지는 않습니다.
- 불꽃값 1은 화재 경보 조건에 반영되고 0으로 바뀌면 해제됩니다. 가스 AO/DO 값은 원시값으로 표시합니다. 첨부 코드처럼 `GAS_MODE`와 기준값이 정해지지 않아 현재는 가스 위험 판정을 하지 않습니다.
- 첨부된 Python 파일은 RoboDog를 별도로 직접 움직이므로, 통합 배송 프로그램과 동시에 실행하지 마세요. 두 프로그램이 모터 명령을 서로 덮어쓸 수 있습니다.
- 첨부 코드에는 `OBS,...`를 보내는 MakeCode 송신부가 없습니다. 센서 micro:bit 또는 중계 micro:bit가 실제로 이 줄을 USB 시리얼로 보내도록 별도로 구성해야 관제 화면에 데이터가 들어옵니다.

실행 순서
1. ZIP 파일을 모두 압축 풀고 `robodog_abc_delivery.py`와 `pawcare_control.html`을 같은 폴더에 둡니다. ZIP 안에서 Python 파일을 바로 실행하지 마세요.
2. PC에 연결한 micro:bit가 있으면 장치 관리자에서 포트를 확인합니다. 기본값은 COM6입니다.
3. RoboDog를 연결합니다. 이 프로젝트의 기본 RoboDog 포트는 COM8입니다.
4. 통합 프로젝트의 `robodog_abc_delivery.py`만 Thonny에서 실행합니다.
5. 브라우저에서 `http://127.0.0.1:8765/`를 엽니다.
6. 화면에서 micro:bit 연결 상태와 관측소 1·2의 불꽃·가스 원시값을 확인합니다.

주의
- HTML 지도상의 위치는 엔코더나 절대 위치 센서가 아닌 이동량·자이로 기반 추정값입니다. 실제 점 도착 여부는 실기기 주행으로 확인해야 합니다.
- 두 관측소 신호가 끊겼을 때 운행을 막는 동작과 가스 임계값은 아직 통합되지 않았습니다. 관제 화면에는 연결 상태와 원시값이 표시됩니다.
- `E/F/G/H + 위치` 라디오 메시지는 위 `OBS,...` 센서 패킷과 다른 형식입니다. 첨부 코드만으로는 두 형식이 서로 변환되지 않습니다.
